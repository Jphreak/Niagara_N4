=====================================================================
 SetFlagEditor v1.03  -  Niagara 4.15.2 Program Object setup
=====================================================================

PURPOSE
  Companion to SetFlagAudit. Same search (Root Location or BQL,
  Slot Name(s), Filter by Name, Flag required), then adds, removes or
  resets the instance flags on every matched slot.

    new flags = (current | Flags to Add) & ~Flags to Remove
    Reset to Default = back to the type default flags

  The dryRun action previews every change and writes nothing.
  Execute writes. Always Dry Run first.
  Every matched slot is logged to the CSV with Before / After flags.
  Each write is read back; a slot that doesn't take the change is
  logged FAILED. Changes persist when the station is saved.
  This program and everything inside it are never edited.

  Leave Execute On Change OFF.
  Undo the last live run with the reverse action.

---------------------------------------------------------------------
 REVERSE
---------------------------------------------------------------------
 - Every LIVE Execute that changes at least one slot overwrites the
   reverse manifest:
     <station home>/logs/SetFlagEditor_<programName>_reverse.csv
   Columns: Path, Slot, BeforeHex, AfterHex (exact flag bits).
 - A live run that changes nothing keeps the previous manifest.
   Dry Run never touches it.
 - Reverse puts each slot back to BeforeHex, but only if its flags
   still equal AfterHex. Anything edited since is SKIPPED.
 - A live Reverse renames the manifest to
     SetFlagEditor_<programName>_reversed_<timestamp>.csv
   so it can't be applied twice. Reverse with no manifest does nothing.
 - Only the LAST live run can be reversed. Older runs: use the Before
   column of that run's CSV (directory mode keeps every run).
 - Save the station after a live Reverse.
 - Reverse CSV goes to Output CSV file; in directory mode it is named
   SetFlagEditor_Reverse_<timestamp>.csv.
 - Reverse results: REVERSED / SKIPPED / FAILED


---------------------------------------------------------------------
 SLOT NOTES
---------------------------------------------------------------------
 Root Location or BQL
               Component  -> walks its whole subtree.
                 station:|slot:/Drivers/BacnetNetwork
               BQL / NEQL -> every row is walked as its own root.
                 station:|slot:/Drivers|bql:select * from control:ControlPoint where name like '*Flow_SP'

 Slot Name(s)  Comma list, actions or properties. Blank = set.
                 set, fallback

 Filter by Name
               Component name contains (case-insensitive). Blank = all.

 Flag required Only edit slots that currently have ALL of these flags.
               Blank = all. e.g. "operator" to touch only slots that
               already have operator.

 Flags to Add / Flags to Remove
               Comma list of flag names. A flag in both stops the run.
               An unknown flag name (typo) stops the run.
               Both blank and Reset to Default off = nothing to do, stops.

 Reset to Default
               Sets each matched slot back to its type default flags.
               Flags to Add / Remove are ignored.

 Max. Results  Caps CSV rows and Results lines only. Every matched
               slot is still edited. 0 = no CSV cap, 200 Results lines.

 Output CSV file
               File       file:^reports/FlagEdits.csv  (overwritten)
               Directory  file:^reports  (new SetFlagEditor_<ts>.csv)
               Must be under the station home. Blank = no CSV.
               Use a directory to keep a history of every run.

 Valid flag names (case-insensitive):
   readonly, transient, hidden, summary, async, noRun,
   defaultOnClone, confirmRequired, operator, noAudit, composite,
   removeOnClone, metadata, linkTarget, nonCritical,
   userDefined1, userDefined2, userDefined3, userDefined4

 CAUTION
   transient on a property = value is NOT saved to the bog.
   readonly blocks operator writes to that slot.
   hidden removes it from the property sheet.
   Test on one point (Filter by Name) before a wide run.
