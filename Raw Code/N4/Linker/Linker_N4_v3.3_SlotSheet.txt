What goes in the fields
-----------------------
  operationMode  Direct = every source linked to targetOrd / targetSlot
                 BQL    = every source linked to each query row
                 CSV    = pairs from a 5-column CSV at targetOrd:
                          BOrd1, Slot1, Direction (> or <), BOrd2, Slot2
  linkSource     one "ord,slot" per line; first line = primary source
                   slot:/Test_Folder/BXXXXX_OAT,out
                 no slot = out. Names can be typed as Workbench shows
                 them (VAV X-01 is escaped for you).
  targetOrd      Direct: the target component
                 BQL:    station:|slot:/Drivers|bql:select * from control:ControlPoint where name = 'OAT'
                 CSV:    file:^Csv_Logs/Links.csv
  targetSlot     slot on the target the link writes to (e.g. in10)
  sourceNote     (the code never writes it) - type this in before setting Read Only:
                   Source holds one "ord,slot" pair per line. (i.e. slot:/TEST/point,slot)
                   The first non-blank line is the primary source;
                   Further non-blank lines are extra sources (lines starting with # are ignored).
                   Omit the slot (just the ord, no comma) and "out" is assumed.

                   In Direct/BQL mode every source is linked to the target.
  maxArchives    timestamped log / results archives kept per file

Display names: set them with Rename Display Name on each slot
(Workbench keeps them in the displayNames slot).

After adding slots: paste the code and compile. Run Dry Run, then
Verify, before Execute.
