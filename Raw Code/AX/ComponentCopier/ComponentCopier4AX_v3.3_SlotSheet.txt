ComponentCopier4AX v3.3-AX - Slot Sheet (complete, for a new ComponentCopier4AX program)
========================================================================================

No slot or import changes from v3.2-AX: paste the v3.3-AX code into the
existing program and compile.

Imports
-------
  None to add. The code uses full class names (javax.baja.naming.BOrd
  etc.), so the default program;baja dependencies are enough.

Already on every Program (leave as is)
--------------------------------------
  code      program:ProgramCode   Frozen
  execute   Action                Frozen. Runs the configured destinationMode.

------------------

(That's 4 String + 7 Ord + 1 Integer + 1 Boolean + 1 StatusEnum + 6 Actions = 20.)

What goes in the fields
-----------------------
  destinationMode  Direct = copyTo is one destination
                   BQL    = copyTo is a query, each row a destination
                   CSV    = copyTo is a CSV, one destination ord per row
  componentSource  one source ord per line; every source goes to every
                   destination. A trailing * copies the folder's
                   CONTENTS instead of the folder:
                     station:|slot:/Drivers/Templates/BXXXXX_VAV/*
  copyTo           Direct: station:|slot:/Drivers/BacnetNetwork/BXXXXX_VAV_01/points
                   BQL:    station:|slot:/Drivers|bql:select * from bacnet:BacnetPointDeviceExt where name = 'points'
                   CSV:    file:^Csv_Logs/Destinations.csv
  linksCsvPath     optional 5-column links CSV (same format as Linker)
                   run after the copy. componentSource and copyTo both
                   blank + linksCsvPath set = links only.
  keepAllLinks     true = keep incoming links on the copied component
  maxArchives      timestamped log / results archives kept per file

Display names: set them with Rename Display Name on each slot
(Workbench keeps them in the displayNames slot).

After adding slots: paste the code and compile. Run Dry Run, then
Verify, before Execute.
