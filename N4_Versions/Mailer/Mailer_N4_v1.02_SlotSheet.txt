What goes in the fields
-----------------------
  files        one per line, # = comment
                 file:^Csv_Logs/Report.csv              one file
                 file:^Csv_Logs/Monthly_Reports/*.csv   wildcard
                 file:^Csv_Logs/Monthly_Reports         every file in it
               paths start at the top of the station's Files; a
               wildcard only looks in the folder you name
               add "=> addresses" for that line's own recipients:
                 file:^Csv_Logs/Report BXXXXX.csv => a@company.com; cc: b@company.com; bcc: c@company.com
               no prefix = To. Lines with no => go to 'to'.
               One email per line; lines with the same recipients are
               combined into one email.
  to           default To for lines without =>  (a@x.com; b@x.com)
  cc / bcc     added to EVERY email
  subject      email subject; blank = Automated Report - {reportname}
  body         email text; blank = This is automated report {reportname}
               autogenerated @ {time} {date}
               Placeholders (both): {reportname} = attached file name(s)
               without extension, {time} = HH:mm, {date} = yyyy-MM-dd
  fromAddress  blank = the sending account's default
  sender       pick the outgoing account (Default = the first one)
  latestOnly   true = each wildcard / folder line sends only its newest
               file. Or start a single line with "latest:".
               Newest is per line (B*.csv -> one file total).
  configFile   where Save Config / Load Config keep the settings:
               a file  file:^Backups/Mailer_Reports.properties
               a folder file:^Backups  -> Backups/<program name>.properties
               (blank = folder file:^Mailer_Config)

After adding slots: paste the code, compile, then run Refresh Accounts
once so the sender drop-down fills in.

Moving to a new Mailer: on the old one run Save Config. On the new one
set configFile to the same path (or give it the same name and leave
configFile blank), compile, then run Load Config.
