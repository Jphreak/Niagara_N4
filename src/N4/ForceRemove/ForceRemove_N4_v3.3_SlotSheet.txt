What goes in the fields
-----------------------
  operationMode  Direct = walk each target and delete matching items
                 BQL    = targetOrd is a BQL query, each row a target
                 CSV    = targetOrd is a one-column CSV (header Ord)
  targetOrd      Direct: a root; BQL: the query; CSV: the file
                   station:|slot:/Drivers/BacnetNetwork/BXXXXX_VAV_01
                   station:|slot:/Drivers|bql:select * from control:ControlPoint where name like 'TEST*'
                   file:^Csv_Logs/RemoveList.csv
                 Leave it blank in a template bog. Never ship a whole-
                 station query here (e.g. select * from baja:Component)
                 - Execute would hit every unprotected component.
  targetList     Direct only: one ord per line, # = comment. Used
                 instead of targetOrd when not empty.
  nameFilter     only items whose name CONTAINS this text (case-
                 sensitive, no wildcards); blank = all. Applied to
                 every row in BQL/CSV mode too.
  typeFilter     exact module:Type, e.g. control:NumericWritable;
                 blank = all. Not applied to folders.
  maxArchives    timestamped log / results archives kept per file

  Protected (never deleted, any mode, Dry Run too): the station root,
  the Services tree, the /Drivers container itself, this program, its
  backup folder, and the folder it lives in with everything inside.

Display names: set them with Rename Display Name on each slot
(Workbench keeps them in the displayNames slot).

After adding slots: paste the code and compile. Back up the station
(.dist) and always run Dry Run before Execute.
