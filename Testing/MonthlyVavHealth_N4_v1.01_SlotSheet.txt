MonthlyVavHealth v1.01 - Slot Sheet
===================================

Imports
-------
  None. Everything used is in the predefined imports
  (java.util, javax.baja.sys, javax.baja.status, javax.baja.util).
  No email module import needed (looked up by name at run time).

Slots, grouped by type
----------------------
Flags: s = Summary, r = Read Only, h = Hidden
"Execute On Change" = tick that box on the slot.
