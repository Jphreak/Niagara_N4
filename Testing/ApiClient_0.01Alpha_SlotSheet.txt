-------------------------------------------------------------------------------------
 FLAGS KEY
-------------------------------------------------------------------------------------
  r = Readonly     t = Transient     h = Hidden     (blank = no flags)
  Transient outputs keep large strings and live values out of the bog.
  lastRun and lastVars must NOT be transient (they hold poll and chain state).

-------------------------------------------------------------------------------------
 TOKENS  (usable in url, headers, body, username, secret)
-------------------------------------------------------------------------------------
  {var1}..{var4}   value of linked varN
  {epochMs}        current time, epoch milliseconds
  {epochS}         current time, epoch seconds
  {isoNow}         current time UTC, yyyy-MM-ddTHH:mm:ssZ
  Add |url to URL-encode, e.g.  ?q={var1|url}


-------------------------------------------------------------------------------------
 PATH SYNTAX  (path1..path10)
-------------------------------------------------------------------------------------
  $                              whole document (or whole body if not JSON)
  data.temp                      object member
  items[0].name / items[-1]      array index (negative = from end)
  Result[SensorID=123].Reading   first array element whose SensorID == 123
  Result[?(@.SensorID==123)]     same, JSONPath filter style
  ['key.with.dots']              bracket key
  items.#   or  items[#]         array length / object member count


-------------------------------------------------------------------------------------
 EXAMPLES  (the object is generic - any HTTP/REST API that returns JSON or text)
-------------------------------------------------------------------------------------
 First time on any new API: set discover = true, fire 'run', and copy the paths you
 want from the 'discovered' slot into path1..path10. Set discover back to false.

 A) OpenWeather - current weather (Calgary)
  method     GET
  url        https://api.openweathermap.org/data/2.5/weather?lat=51.0447&lon=-114.0719&units=metric&appid=<key>
  authType   none
  pollSecs   600                    (data updates ~10 min; free tier is rate limited)
  path1      main.temp              -> num1  degC
  path2      main.humidity          -> num2  %RH
  path3      main.feels_like        -> num3  degC
  path4      main.pressure          -> num4  hPa
  path5      wind.speed             -> num5  m/s  (x 3.6 for km/h)
  path6      wind.deg               -> num6  deg
  path7      weather[0].description -> str7  e.g. "light snow"
  path8      clouds.all             -> num8  %
  path9      rain['1h']             -> num9  mm   (absent when not raining -> null)
  path10     snow['1h']             -> num10 mm   (absent when not snowing -> null)
  Notes: units=imperial gives degF and mph. Use lat/lon - city-name lookup (q=) is
  deprecated by OpenWeather. The appid sits in the url in plain text.

 B) iMonnit - SensorList
  method     POST
  url        https://www.imonnit.com/json/SensorList?NetworkID=<id>
  headers    APIKeyID: <key>|APISecretKey: <secret>
  authType   none
  path1      Result[SensorID=<id>].CurrentReading
  path2      Result[SensorID=<id>].BatteryLevel
  path3      Result[SensorID=<id>].LastCommunicationDate

 C) Two-step token API (login -> data), two ApiClient objects
  ApiLogin:  method POST
             url    https://api.example.com/auth/token
             body   {"username":"<user>","password":"<pass>"}
             path1  access_token            -> str1
             pollSecs 3000                  (refresh before the token expires)
  ApiData:   link ApiLogin.str1 -> ApiData.var1
             method   GET
             url      https://api.example.com/v1/points
             authType bearer
             secret   {var1}
             path1..  whatever the data response needs
  ApiData waits ("Waiting for var1") until the login succeeds, then fires right away
  each time the token changes.

 D) API key in a header (common pattern)
  headers    x-api-key: <key>
  or         Authorization: ApiKey <key>      (leave authType = none)
